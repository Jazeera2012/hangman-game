# 🐍 Python Dictionary

An interactive Python terminology learning game designed to help you learn and review important Python concepts through different game modes.

## 🎮 Features

* 📖 Definition → Guess the Python Term
* 🧠 Term → Explain the Definition
* 🎯 Multiple Choice
* ❤️ Hangman-style letter guessing
* 🎚️ Easy, Medium, and Hard difficulties
* ⭐ Score system
* 🔥 Streak system
* 🏆 Personal best
* 📊 Statistics
* 📜 Game history
* 📚 Browse Python terms
* 💡 Definitions and code examples
* 🔤 Input validation
* 🎲 Random Python terms

## 🎮 Game Modes

### 1. Definition → Guess the Term

Read the definition and guess the Python term one letter at a time.

You have 6 lives, and every incorrect letter costs one life.

### 2. Term → Guess the Definition

You are given a Python term and try to explain what it means.

The game checks your answer for important words from the definition.

### 3. Multiple Choice

Choose the correct definition from four possible answers.

## 🎚️ Difficulty

| Difficulty | Points |
| ---------- | -----: |
| 🟢 Easy    |     10 |
| 🟡 Medium  |     20 |
| 🔴 Hard    |     30 |

Correct answers can also increase your score through the streak bonus.

## 📊 Statistics

The game tracks:

## 📜 Game History

After each round, the game records:

* 🐍 Python term
* 🎚️ Difficulty

Make sure Python is installed on your computer.

Clone the repository and run:

```bash

```
